# 🧠 Lokha Letta AI Memory Server

Stateful, perpetual long-term memory AI agent server (built with Letta / MemGPT) deployed on Railway for **Lokha.Today**.

## Features:
- **Perpetual Memory**: Core memory blocks (human & persona) + Archival memory + Recall memory.
- **REST API & Web ADE**: Full agent development environment and chat interface on port `8283`.
- **MCP Tool Integration**: Connected to `lokha-mcp` for Ghost CMS publishing and Buffer social queueing.
